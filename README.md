sales Performance Dashboard
Project Overview

This project is an interactive Sales Performance dashboard built using Microsoft Power BI to analyze sales, profit, and order trends across regions, categories, and customer segments. The dashboard provides a clear, drill-down view of business performance to support data-driven decision-making.

Tools & Technologies:
Power BI
Power Query
DAX
Data Visualization

Key KPIs:
Total Sales
Total Orders
Total Quantity
Total Profit
Profit Margin %
Key Analysis

The dashboard covers:

Sales, profit, orders, and quantity by U.S. state (map view)
Sum of sales trend by year
Sum of sales by state
Total profit by sub-category
Sum of profit by region
Sum of profit by ship mode
Sum of profit by category
Sum of profit by customer segment

Dashboard Features:
Interactive KPI cards
Dynamic filters and slicers (Category, Sub-Category, Ship Mode, Region, Segment)
Geographic map visualization of sales by state
Multiple visualizations for sales and profit insights
Two-page interactive dashboard
